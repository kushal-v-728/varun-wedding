# Page music

Drop **one** audio file in this folder (`.mp3`, `.m4a`, `.ogg` or `.wav`) and it
becomes the wedding site's soundtrack — it is picked up automatically on the
next build, no code changes needed.

- Name it anything, e.g. `wedding-song.mp3`.
- It starts as the cover doors open, fades in gently, and stops when the track
  ends (never loops). The small disc at the bottom-left lets guests pause it.
- Around 30–40 seconds is ideal; anything longer is cut off at 40 seconds.
- **Mute toggle tip:** browsers block audio that starts without a tap, so when
  the doors open by themselves the guest sees a small "tap for music" disc.
  If they tap the doors, the music starts straight away.

Keep the file small (under ~1 MB) so phones on mobile data stay quick.
